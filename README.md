# SpankBang - Listas PRO

**Última Actualización:** 14 de julio de 2026

Muestra etiquetas coloridas sobre los videos que pertenecen a tus listas de **SpankBang**, con borde luminoso, carga automática y actualización manual desde el menú de Tampermonkey.

## 📖 Descripción

**SpankBang - Listas PRO** es un UserScript para **Tampermonkey** que identifica automáticamente los videos que forman parte de tus listas de reproducción de SpankBang.

Cada video perteneciente a una o varias listas recibe etiquetas de colores con el nombre de la lista, además de un borde luminoso para facilitar su identificación mientras navegas por el sitio.

El script guarda localmente toda la información obtenida, por lo que no necesita volver a descargar las listas cada vez que recargas una página.

---

# 📥 Instalación

1. Instala la extensión **Tampermonkey** para tu navegador.

2. Instala el script desde GitHub:

**➡️ [Instalar Script](https://github.com/wernser412/SpankBang-tags/raw/refs/heads/main/SpankBang%20-%20Listas%20PRO.user.js)**

---

# ✨ Características

- 📁 Muestra etiquetas con el nombre de cada lista.
- 🎨 Colores automáticos para diferenciar las listas.
- ✨ Borde luminoso animado en los videos encontrados.
- ⚡ Utiliza la información almacenada sin volver a descargar las listas al recargar la página.
- 🔄 Actualización manual desde el menú de Tampermonkey.
- 📊 Indicador de progreso durante la actualización.
- 🔔 Mensajes visuales con el estado de las operaciones.
- 📦 Guarda automáticamente todas las listas y videos procesados.
- ♾️ Compatible con la carga dinámica de videos (scroll infinito).
- 🧹 Elimina automáticamente etiquetas antiguas cuando una lista cambia.
- 🚫 Aviso automático cuando todavía no existen listas cargadas.

---

# 🖥️ Uso

1. Abre cualquier página de **SpankBang**.
2. Desde el menú de **Tampermonkey**, selecciona **🔄 Actualizar listas**.
3. Espera a que finalice la descarga de tus listas.
4. Navega normalmente por el sitio.
5. Los videos que pertenezcan a tus listas aparecerán automáticamente etiquetados.

---

# 💾 Información almacenada

El script recuerda automáticamente:

- Todas las listas encontradas en tu cuenta.
- La relación entre videos y listas.
- La información necesaria para evitar volver a descargar las listas en cada recarga.

---

# 🔄 Actualización de listas

Cuando agregues o elimines videos de tus listas de SpankBang, simplemente ejecuta nuevamente:

**Tampermonkey → 🔄 Actualizar listas**

El script descargará nuevamente la información y actualizará todas las etiquetas automáticamente.
